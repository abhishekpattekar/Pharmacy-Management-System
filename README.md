# 💊 Pharmacy Management System

A Python-based web application built using Streamlit to efficiently manage pharmacy inventory, medicine stock, and customer billing.

## ✨ Features
- **Inventory Management:** Add, update, and delete medicines with expiry dates and stock quantities.
- **Billing System:** Generate quick bills for customers and automatically update stock levels.
- **Search & Filter:** Easily search medicines by name or category.

## 🛠️ Technologies Used
- **Language:** Python
- **Framework:** Streamlit
- **Database:** SQLite / PostgreSQL
